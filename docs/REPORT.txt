1. LỰA CHỌN BỘ SIÊU THAM SỐ DỰA TRÊN THỰC NGHIỆM MLFLOW (BƯỚC 1)
================================================================================
Trên tập dữ liệu Wine Quality gốc (2.998 mẫu huấn luyện, 500 mẫu đánh giá), mô hình RandomForestClassifier được thực nghiệm qua 4 bộ siêu tham số và ghi nhận trên MLflow UI:
- Lần 1: n_estimators = 100, max_depth = 5,  min_samples_split = 2  ==> Accuracy = 0.5640 | F1 = 0.5534
- Lần 2: n_estimators = 150, max_depth = 10, min_samples_split = 5  ==> Accuracy = 0.6440 | F1 = 0.6408
- Lần 3: n_estimators = 300, max_depth = 20, min_samples_split = 2  ==> Accuracy = 0.6740 | F1 = 0.6729
- Lần 4: n_estimators = 500, max_depth = 30, min_samples_split = 2  ==> Accuracy = 0.6800 | F1 = 0.6788

* Bộ siêu tham số tối ưu được chọn: n_estimators = 500, max_depth = 30, min_samples_split = 2.
* Lý do: Đạt độ chính xác cao nhất (68.0%) và F1-score có trọng số cao nhất (67.88%). Số lượng cây lớn (500) kết hợp với độ sâu hợp lý (30) giúp mô hình nắm bắt tối đa mối quan hệ phi tuyến giữa các đặc trưng hóa lý của rượu vang mà vẫn kiểm soát tốt hiện tượng overfitting.

3. KHÓ KHĂN GẶP PHẢI VÀ GIẢI PHÁP KHẮC PHỤC
================================================================================
1. Phân quyền IAM S3 trên AWS:
   - Khó khăn: IAM User ban đầu thiếu quyền s3:CreateBucket và s3:ListAllMyBuckets khiến CLI báo AccessDenied khi khởi tạo remote storage.
   - Giải pháp: Gắn policy AmazonS3FullAccess trực tiếp cho IAM User, sau đó tạo thành công bucket "mlops-wine-duy24ithust-2026".

2. Kích hoạt GitHub Actions trên Forked Repository:
   - Khó khăn: GitHub mặc định disable Actions trên repo fork.
   - Giải pháp: Bật quyền chạy Actions trong tab Actions và cấu hình 5 Repository Secrets chuẩn xác (CLOUD_CREDENTIALS, CLOUD_BUCKET, VM_HOST, VM_USER, VM_SSH_KEY).

3. Xử lý chuỗi Credentials trong Runner Linux:
   - Khó khăn: Trình thông dịch Python 3.10 trên GitHub Actions báo lỗi SyntaxError với escape backslash trong f-string.
   - Giải pháp: Tách biến và trích xuất trực tiếp từ JSON object để ghi biến môi trường vào $GITHUB_ENV.

4. Đồng bộ dữ liệu DVC trước khi push Git:
   - Khó khăn: Nguy cơ pipeline thất bại nếu dvc pull chạy trước khi dữ liệu kịp đưa lên S3.
   - Giải pháp: Áp dụng nghiêm ngặt thứ tự: dvc add -> dvc push lên S3 -> git commit file .dvc -> git push.
