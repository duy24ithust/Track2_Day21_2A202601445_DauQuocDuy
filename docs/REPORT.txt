1. KẾT QUẢ THỰC NGHIỆM VÀ LỰA CHỌN BỘ SIÊU THAM SỐ (BƯỚC 1)
================================================================================
Trong Bước 1, mô hình RandomForestClassifier được huấn luyện trên tập dữ liệu Wine Quality (2998 mẫu) với 4 bộ siêu tham số khác nhau và được theo dõi bằng MLflow:
- Lần 1: n_estimators = 100, max_depth = 5,  min_samples_split = 2  ==> Accuracy = 0.5640 | F1 = 0.5534
- Lần 2: n_estimators = 150, max_depth = 10, min_samples_split = 5  ==> Accuracy = 0.6440 | F1 = 0.6408
- Lần 3: n_estimators = 300, max_depth = 20, min_samples_split = 2  ==> Accuracy = 0.6740 | F1 = 0.6729
- Lần 4: n_estimators = 500, max_depth = 30, min_samples_split = 2  ==> Accuracy = 0.6800 | F1 = 0.6788

* Bộ siêu tham số được chọn: n_estimators = 500, max_depth = 30, min_samples_split = 2.
* Lý do lựa chọn: Bộ tham số này đạt độ chính xác (Accuracy: 68.0%) và điểm F1 có trọng số (F1-score: 67.88%) cao nhất trên tập đánh giá (eval.csv). Độ sâu cây (max_depth = 30) cùng số lượng cây lớn (500 cây) giúp mô hình học được các tương tác phi tuyến phức tạp giữa 12 đặc trưng hóa học của rượu vang mà không làm suy giảm tính tổng quát hóa.

3. KHÓ KHĂN GẶP PHẢI VÀ GIẢI PHÁP KHẮC PHỤC
================================================================================
1. Quyền truy cập Cloud S3 (IAM Permission):
   - Khó khăn: Tài khoản IAM User ban đầu bị thiếu quyền s3:CreateBucket và s3:ListAllMyBuckets dẫn đến lệnh tạo bucket và liệt kê bucket qua AWS CLI bị AccessDenied.
   - Giải pháp: Gắn trực tiếp chính sách AmazonS3FullAccess cho user trên AWS IAM Console, sau đó khởi tạo thành công S3 Bucket "mlops-wine-duy24ithust-2026" cho DVC remote storage.

2. Cấu hình GitHub Actions trên Forked Repository:
   - Khó khăn: GitHub tự động vô hiệu hóa tính năng Actions đối với các repository được fork về tài khoản cá nhân để tránh chạy workflow không mong muốn.
   - Giải pháp: Truy cập tab Actions và chọn "I understand my workflows, go ahead and enable them", đồng thời thêm đủ 5 Secrets (CLOUD_CREDENTIALS, CLOUD_BUCKET, VM_HOST, VM_USER, VM_SSH_KEY).

3. Xử lý định dạng chuỗi xác thực trong Workflow CI/CD:
   - Khó khăn: Runner Python 3.10 trên GitHub Actions gặp lỗi cú pháp khi xử lý chuỗi escape lồng nhau trong bước xác thực JSON secret.
   - Giải pháp: Tách biến và đọc trực tiếp từ dictionary Python để truyền chuẩn xác các biến môi trường AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_DEFAULT_REGION vào $GITHUB_ENV.

4. Đồng bộ DVC trước khi kích hoạt CI/CD:
   - Khó khăn: Nếu đẩy git commit trước khi đẩy dữ liệu DVC, GitHub Actions runner sẽ bị lỗi do không tìm thấy file dữ liệu trên S3.
   - Giải pháp: Tuân thủ quy trình chuẩn: dvc add -> dvc push lên S3 trước -> git commit file .dvc -> git push kích hoạt pipeline.
